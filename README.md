### 🚀 Projetos em produção

**⚽ [Porcento](https://porcento-app.vercel.app/) — futebol em probabilidades**  
Predições do Brasileirão apresentadas de forma simples: chance de vitória, empate e derrota, placar provável e classificação projetada rodada a rodada. Interface limpa apoiada por um modelo estatístico próprio.  
`Next.js` · `TypeScript` · `Supabase` · `Vercel` · modelo estatístico (Dixon-Coles)

**📸 [Plating](https://plating-five.vercel.app/) — estúdio de fotos com IA**  
Transforma a foto de um prato tirada no celular em um álbum de fotos profissionais, com versões prontas para cada canal (cardápio, redes, delivery). Feito para pequenos restaurantes e docerias.  
`Next.js` · `TypeScript` · processamento de imagem · IA generativa
